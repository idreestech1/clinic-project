# Doctor Project

This project is split into separate frontend and backend folders.

## Folders

- `frontend/` - React + Vite app
- `backend/` - Node + Express API

## Run Frontend

```bash
npm run frontend:dev
```

Frontend URL:

```text
http://localhost:5173
```

## Run Backend

```bash
npm run backend:dev
```

Backend URL:

```text
http://localhost:5000/api
```
